# Reading Edge

无需 AI 的英语阅读定级 MVP。系统根据国内外考试成绩、成绩年份、阅读自评和学习阶段，保守推算 A1–C2 起始档位；随后用同级阅读实测校准结果。

内置 A1–C2 共 30 套固定测试（每级 5 篇文章）。系统进入对应等级后随机抽取 1 篇；每篇包含文章、点词语境释义，以及词汇、句子、语篇三个层次的 6 道固定题目。题目顺序不变，但每次测试都会打乱各题选项顺序。

## 本地运行

```bash
npm install
npm run dev
```

打开 `http://localhost:3000`。

运行完整检查：

```bash
npm test
npm run lint
```
